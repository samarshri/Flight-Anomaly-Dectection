## 💡 Learning Tips

### 1. **Type the Code**
Don't just read - actually type examples into Python!

```powershell
# Open Python
py

# Try examples
>>> speed = 850
>>> duration = 120
>>> speed_per_min = speed / duration
>>> print(speed_per_min)
```

### 2. **Break Things!**
- Change values and see what happens
- Comment out code to understand its purpose
- This is how you truly learn

### 3. **Use Print Statements**
```python
print("Speed:", speed)
print("Type:", type(speed))
```

### 4. **Take Notes**
Create your own notes file with:
- Key concepts you learned
- Questions you have
- Examples that helped you understand

### 5. **Practice Projects**
After each section, try to build something small:
- Week 1: Calculator program
- Week 2: To-do list with lists
- Week 3: File backup script
- Week 4: Database contact book
- Week 5: Simple website
- Week 6: Your own anomaly detector
